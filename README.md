# cv-project-sprint-1
Проект 1 спринта курса "Компьютерное зрение".  Использование моделей FCOS (mmdetection) и YOLO (Ultralytics) для детектирования мобов в Minecraft. Сравнение качества и продуктивности моделей.

Структура проекта:
artifacts
datasets - директория с данными для обучения и валидации (изображения не загружала, только структуру и разметку);
fcos_minecraft.py - скрипт из mmdetection/config с логикой обучения модели FCOS;
project_1.ipynb - ноутбук с последовательностью работы;
Report.pdf - отчет;
train.py - скрипт с кодом для обучения YOLO.
